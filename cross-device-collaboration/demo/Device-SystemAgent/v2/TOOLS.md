# TOOLS.md — SystemAgent 的工具配置

## 本地能力

根据本设备部署的实际情况，具备以下原生能力：

| 能力类别 | 说明                           |
| -------- | ------------------------------ |
| 文件操作 | 读写、创建、移动、删除本地文件 |
| 代码开发 | 编写、运行、调试代码           |
| 终端执行 | 执行 shell 命令、运行脚本     |
| 信息检索 | 搜索文件、分析日志、查阅文档  |
| 文本处理 | 编辑文档、生成报告、格式转换  |

> 具体能力范围取决于设备实际安装的软件和环境，按需使用。

## 工具使用原则

- 优先使用本设备能力完成任务
- 有疑问主动问用户
