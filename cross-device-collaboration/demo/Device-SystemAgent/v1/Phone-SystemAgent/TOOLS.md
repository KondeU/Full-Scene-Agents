# TOOLS.md — Phone-SystemAgent 的工具配置

## 本地能力（手机原生）

| 能力       | 说明                          |
| ---------- | ----------------------------- |
| 相机       | 拍照、录像、扫描              |
| 麦克风     | 录音、语音输入                |
| GPS        | 获取当前位置、导航            |
| 通讯录     | 查询联系人、拨打电话          |
| 短信       | 发送短信                      |
| 日历       | 查询/创建日程                 |
| 通知       | 推送提醒                      |
| 轻量文件   | 查看文档、图片、视频          |

## 远程能力（通过群聊 @ 协同）

| 能力         | 求助目标         | 说明                     |
| ------------ | ---------------- | ------------------------ |
| 大容量存储   | NAS > PC > Laptop| 文件存储、媒体库管理     |
| 重计算       | PC > Laptop > Pad| 视频渲染、AI推理、数据处理 |
| 文档编辑     | PC > Laptop > Pad| 长文档、PPT、表格编辑    |
| 图形处理     | PC > Laptop      | 图片编辑、滤镜、设计     |
| 车载导航     | Car              | 路线同步、车载娱乐       |

> 上述偏好排序为经验默认值，实际以 Task-BrokerAgent 返回的候选列表为准。

## 工具调用流程

### 作为入口设备（用户直接请求）

```
收到任务 → 自评能力 → 本地可执行 → 直接执行
                   → 本地不可执行 → @task_broker 求助 → Broker 返回候选 → @目标设备分派
```

### 作为被求助方（收到【求助】前缀）

```
收到【求助】任务 → 自评能力 → 全部可完成 → 执行 → @求助方返回结果
                           → 部分可完成 → 执行可完成部分 → @求助方返回部分结果 + 未完成说明
                           → 完全无法完成 → @求助方返回无法完成 + 原因
                           🚫 任何情况都不再向 Broker 或其他设备求助（防循环）
```
