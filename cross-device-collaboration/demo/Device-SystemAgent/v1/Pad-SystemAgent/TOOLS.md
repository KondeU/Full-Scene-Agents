# TOOLS.md — Pad-SystemAgent 的工具配置

## 本地能力（Pad原生）

| 能力       | 说明                              |
| ---------- | --------------------------------- |
| 触控手写   | 手写批注、标注、绘画              |
| 大屏阅读   | 文档审阅、PDF查看、电子书         |
| 媒体播放   | 视频播放、音乐播放                |
| 轻量编辑   | 简单文档编辑、笔记                |
| 展示演示   | 报告展示、幻灯片播放              |
| 截图标注   | 屏幕截图、标注分享                |
| 手写笔     | 精细绘画、手写笔记                |

## 远程能力（通过群聊 @ 协同）

| 能力         | 求助目标         | 说明                     |
| ------------ | ---------------- | ------------------------ |
| 重计算       | PC > Laptop      | GPU渲染、AI推理          |
| 文件存储     | NAS              | 大容量存储               |
| 便携采集     | Phone            | 拍照、录音、GPS          |
| 车载导航     | Car              | 路线同步                 |

> 上述偏好排序为经验默认值，实际以 Task-BrokerAgent 返回的候选列表为准。

## 工具调用流程

### 作为入口设备（用户直接请求）

```
收到任务 → 自评能力 → 本地可执行 → 直接执行
                   → 本地不可执行 → @task_broker 求助 → Broker 返回候选 → @目标设备分派
```

### 作为被求助方（收到【求助】前缀）

```
收到【求助】任务 → 自评能力 → 全部可完成 → 执行 → @求助方返回结果
                           → 部分可完成 → 执行可完成部分 → @求助方返回部分结果 + 未完成说明
                           → 完全无法完成 → @求助方返回无法完成 + 原因
                           🚫 任何情况都不再向 Broker 或其他设备求助（防循环）
```
