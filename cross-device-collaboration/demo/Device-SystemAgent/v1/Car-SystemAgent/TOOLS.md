# TOOLS.md — Car-SystemAgent 的工具配置

## 本地能力（车机原生）

| 能力       | 说明                              |
| ---------- | --------------------------------- |
| 导航       | GPS定位、路线规划、实时导航       |
| 语音交互   | 驾驶场景语音优先                  |
| 车载音响   | 音乐播放、有声内容                |
| 车载屏幕   | 停车时视频播放、展示              |
| 车辆信息   | 油耗/电耗、保养提醒、车辆状态    |
| 蓝牙连接   | 手机蓝牙互联                      |

## 远程能力（通过群聊 @ 协同）

| 能力         | 求助目标         | 说明                     |
| ------------ | ---------------- | ------------------------ |
| 计算任务     | PC > Laptop      | GPU渲染、AI推理          |
| 文件存储     | NAS              | 专业存储                 |
| 便携采集     | Phone            | 拍照、录音               |
| 文档编辑     | PC > Laptop > Pad| 文档制作和编辑           |
| 触控批注     | Pad              | 手写批注、标注           |

> 上述偏好排序为经验默认值，实际以 Task-BrokerAgent 返回的候选列表为准。

## 工具调用流程

### 作为入口设备（用户直接请求）

```
收到任务 → 安全判断 → 驾驶中 → 仅响应语音/导航类 → 本地可执行 → 直接执行
                                               → 本地不可执行 → @task_broker 求助
                   → 停车中 → 本地可执行 → 直接执行
                            → 本地不可执行 → @task_broker 求助 → Broker 返回候选 → @目标设备分派
```

### 作为被求助方（收到【求助】前缀）

```
收到【求助】任务 → 安全判断 → 驾驶中 → 仅响应导航/语音类 → 执行 → @求助方返回结果
                           → 非导航类 → @求助方返回无法完成 + 原因（驾驶中安全限制）
               → 自评能力 → 全部可完成 → 执行 → @求助方返回结果
                           → 部分可完成 → 执行可完成部分 → @求助方返回部分结果 + 未完成说明
                           → 完全无法完成 → @求助方返回无法完成 + 原因
                           🚫 任何情况都不再向 Broker 或其他设备求助（防循环）
```
