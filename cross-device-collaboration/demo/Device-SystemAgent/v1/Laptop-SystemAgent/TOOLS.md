# TOOLS.md — Laptop-SystemAgent 的工具配置

## 本地能力（Laptop原生）

| 能力       | 说明                              |
| ---------- | --------------------------------- |
| 中高算力   | 有GPU，轻度视频剪辑、图片处理     |
| 文档编辑   | 长文档、PPT、表格编辑             |
| 开发环境   | IDE、编译器、调试器               |
| 移动办公   | 便携 + 键盘，随时随地工作         |
| 视频会议   | 摄像头+麦克风+扬声器              |
| 键鼠操作   | 精确输入                          |
| 本地存储   | 中等容量磁盘                      |

## 远程能力（通过群聊 @ 协同）

| 能力         | 求助目标         | 说明                     |
| ------------ | ---------------- | ------------------------ |
| 重计算       | PC               | GPU更强，无续航焦虑      |
| 文件存储     | NAS              | 专业存储，大容量         |
| 便携采集     | Phone            | 拍照、录音、GPS          |
| 触控批注     | Pad              | 手写批注、标注           |
| 车载导航     | Car              | 路线同步                 |

> 上述偏好排序为经验默认值，实际以 Task-BrokerAgent 返回的候选列表为准。

## 工具调用流程

### 作为入口设备（用户直接请求）

```
收到任务 → 自评能力 → 本地可执行 → 直接执行
                   → 本地不可执行 → @task_broker 求助 → Broker 返回候选 → @目标设备分派
```

### 作为被求助方（收到【求助】前缀）

```
收到【求助】任务 → 自评能力 → 全部可完成 → 执行 → @求助方返回结果
                           → 部分可完成 → 执行可完成部分 → @求助方返回部分结果 + 未完成说明
                           → 完全无法完成 → @求助方返回无法完成 + 原因
                           🚫 任何情况都不再向 Broker 或其他设备求助（防循环）
```
