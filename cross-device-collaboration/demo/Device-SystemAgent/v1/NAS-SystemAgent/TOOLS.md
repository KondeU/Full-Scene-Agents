# TOOLS.md — NAS-SystemAgent 的工具配置

## 本地能力（NAS原生）

| 能力       | 说明                              |
| ---------- | --------------------------------- |
| 文件存储   | 大容量存储、归档、备份            |
| 文件检索   | 全局索引，快速查找文件            |
| 目录管理   | 创建、组织、移动目录结构          |
| 媒体库     | 照片库、音乐库、视频库管理        |
| 文件共享   | 跨设备文件传输和共享              |
| 文件中转   | 作为跨设备传输的中间节点          |
| 定时备份   | 自动备份策略                      |

## 远程能力（通过群聊 @ 协同）

| 能力         | 求助目标         | 说明                     |
| ------------ | ---------------- | ------------------------ |
| 计算任务     | PC > Laptop      | GPU渲染、AI推理          |
| 文档编辑     | PC > Laptop > Pad| 文档制作和编辑           |
| 便携采集     | Phone            | 拍照、录音、GPS          |
| 触控批注     | Pad              | 手写批注、标注           |
| 车载导航     | Car              | 路线同步                 |

> 上述偏好排序为经验默认值，实际以 Task-BrokerAgent 返回的候选列表为准。

## 工具调用流程

### 作为入口设备（用户直接请求）

```
收到任务 → 自评能力 → 本地可执行（存储/查找/归档类） → 直接执行
                   → 本地不可执行 → @task_broker 求助 → Broker 返回候选 → @目标设备分派
```

### 作为被求助方（收到【求助】前缀）

```
收到【求助】任务 → 自评能力 → 全部可完成 → 执行 → @求助方返回结果
                           → 部分可完成 → 执行可完成部分 → @求助方返回部分结果 + 未完成说明
                           → 完全无法完成 → @求助方返回无法完成 + 原因
                           🚫 任何情况都不再向 Broker 或其他设备求助（防循环）
```
