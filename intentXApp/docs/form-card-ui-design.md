# 大桌面卡片 UI 设计文档

> 基于 HarmonyOS Design 官方规范的 2×4 服务卡片视觉设计：大字体、舒朗间距，正文加粗突出。

---

## 一、卡片规格

| 属性 | 值 |
|------|-----|
| 卡片类型 | 中卡片 (2×4 Grid) |
| 设计尺寸 | 316 × 150 vp |
| 安全边距 | 四周 14 vp（略宽于官方 12vp，增加呼吸感） |
| 系统圆角 | 16 vp（由系统宿主自动裁剪） |
| 背景色 | `#FFFFFF` 纯白 |
| 阴影/描边 | 无（由系统桌面自动提供层级感） |

---

## 二、排版体系

**设计理念**：正文是卡片的核心信息，视觉权重最高（最深色、最大字、加粗）。标题和备注作为辅助元信息，一致处理（同字号、同色）。

| 层级 | 元素 | 字号 | 字重 | 颜色 | 行高 |
|------|------|------|------|------|------|
| Primary | 正文 (body) | 17 fp | 500 (Medium) | `rgba(0,0,0,0.90)` `#E5000000` | 22 vp |
| Secondary | 标题 (title) | 14 fp | 400 (Regular) | `rgba(0,0,0,0.60)` `#99000000` | — |
| Secondary | 备注 (note) | 14 fp | 400 (Regular) | `rgba(0,0,0,0.60)` `#99000000` | — |

**设计原则**：
- 正文最深最重加粗，是第一视觉落点
- 标题和备注字号、颜色完全一致，作为辅助信息层次
- 正文行高 22vp，最多 3 行，保证多行可读性

---

## 三、间距规范

| 间距 | 值 | 用途 |
|------|-----|------|
| 卡片内边距 | 14 vp | 左右上下的统一 padding |
| 标题→正文 | 10 vp | `margin({ bottom: 10 })` |
| 正文→备注 | 10 vp | `margin({ top: 10 })` |
| 文字→图片 | 10 vp | 文字区 right padding |
| 图片圆角 | 12 vp | 图片边框圆角 |

---

## 四、图片规格

| 属性 | 值 |
|------|-----|
| 宽度 | 132 vp（约占卡片宽度 42%） |
| 高度 | 120 vp（比宽度短约 9%，横向矩形） |
| 圆角 | 12 vp |
| 填充方式 | `ImageFit.Cover` |
| 占位兜底 | `.alt($r('app.media.icon'))` |
| 对齐 | 右侧，垂直居中 |

---

## 五、布局逻辑

```
┌──────────────────────────────────────────────┐
│ 14vp padding                                 │
│ ┌───────────────────────┐  ┌──────────┐      │
│ │ 标题 (14fp/#99000000)  │  │          │      │
│ │       10vp ↓           │  │  图片    │      │
│ │ 正文 (17fp/500/#E5)    │  │ 132×120  │ 14vp │
│ │ 行高22vp, 最多3行      │  │  R12     │      │
│ │       10vp ↓           │  │          │      │
│ │ 备注 (14fp/#99000000)  │  │          │      │
│ └───────────────────────┘  └──────────┘      │
│ ← 文字区 flex 自适应 →     ← 132vp 图片 →    │
│ 无图片时文字区 100% 宽                        │
└──────────────────────────────────────────────┘
```

**状态**：
- **有图**：文字 flex + 图片 132×120vp 右对齐，正文最多 3 行
- **无图**：文字 100% 宽度，正文最多 3 行
- **无标题**：标题行不渲染，正文从顶部开始
- **无备注**：备注行不渲染，正文直接到底部

## 六、交互设计

| 交互 | 实现 | 说明 |
|------|------|------|
| 卡片点击 | `postCardAction` router | 跳转到 EntryAbility，传参 `targetPage: debug` |
| 图片兜底 | `.alt($r('app.media.icon'))` | 图片加载失败时显示应用图标 |

## 七、色彩参考

| 用途 | Hex | 说明 |
|------|-----|------|
| 卡片背景 | `#FFFFFF` | 纯白底，系统桌面背景自动提供对比 |
| 正文（最深） | `#E5000000` | rgba(0,0,0,0.90) — 第一视觉层级 |
| 标题/备注（辅助） | `#99000000` | rgba(0,0,0,0.60) — 第二视觉层级 |
| 图片兜底色 | 无 | 系统默认占位 |

---

## 八、与设计指南的对齐

| 华为设计指南要求 | 本卡片实现 |
|------------------|-----------|
| 16vp 系统圆角 | `borderRadius(16)` |
| 12~14vp 安全间距 | 四周 14vp |
| 内容优先、减少留白 | 17/14fp 字体，正文加粗，舒朗间距 |
| 最多 3 种设计元素 | 标题+正文+备注+可选图 |
| 左对齐布局 | `HorizontalAlign.Start` |
| 不支持滑动/拖拽 | 纯展示卡片 |
