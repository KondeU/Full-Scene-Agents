# 大桌面卡片 UI 设计文档

> 基于 HarmonyOS Design 官方规范的 2×4 服务卡片视觉设计。支持两种卡片风格，Agent 通过 `style` 参数实时选择。

---

## 零、卡片风格选择机制

Agent 在调用 `card.reminder.update` 时通过 `style` 参数选择渲染哪种卡片：

| style 值 | 卡片名称 | 用途 |
|----------|---------|------|
| `infoShowTitleBodyNoteImage` | 信息展示卡（默认） | 标题+正文+备注+右侧缩略图，通用信息展示 |
| `infoShowTitleImageAndImport` | 图片导入卡（新增） | 全幅背景图 + 右侧快捷导入按钮，引导用户拍照/选图 |

`style` 为可选参数，不传或传未知值时默认使用 `infoShowTitleBodyNoteImage`。

---

## 一、卡片通用规格

两种卡片共享以下规格：

| 属性 | 值 |
|------|-----|
| 卡片类型 | 中卡片 (2×4 Grid) |
| 设计尺寸 | 316 × 150 vp |
| 系统圆角 | 16 vp（由系统宿主自动裁剪） |
| 阴影/描边 | 无（由系统桌面自动提供层级感） |

---

## 二、style=infoShowTitleBodyNoteImage（信息展示卡）

> 这是当前已实现的卡片风格。左文字右图片的经典信息展示布局。

### 2.1 基础规格

| 属性 | 值 |
|------|-----|
| 安全边距 | 四周 14 vp |
| 背景色 | `#FFFFFF` 纯白 |

### 2.2 排版体系

**设计理念**：正文是卡片的核心信息，视觉权重最高（最深色、最大字、加粗）。标题和备注作为辅助元信息，一致处理（同字号、同色）。

| 层级 | 元素 | 字号 | 字重 | 颜色 | 行高 |
|------|------|------|------|------|------|
| Primary | 正文 (body) | 17 fp | 500 (Medium) | `rgba(0,0,0,0.90)` `#E5000000` | 22 vp |
| Secondary | 标题 (title) | 14 fp | 400 (Regular) | `rgba(0,0,0,0.60)` `#99000000` | — |
| Secondary | 备注 (note) | 14 fp | 400 (Regular) | `rgba(0,0,0,0.60)` `#99000000` | — |

**设计原则**：
- 正文最深最重加粗，是第一视觉落点
- 标题和备注字号、颜色完全一致，作为辅助信息层次
- 正文行高 22vp，最多 3 行，保证多行可读性

### 2.3 间距规范

| 间距 | 值 | 用途 |
|------|-----|------|
| 卡片内边距 | 14 vp | 左右上下的统一 padding |
| 标题→正文 | 10 vp | `margin({ bottom: 10 })` |
| 正文→备注 | 10 vp | `margin({ top: 10 })` |
| 文字→图片 | 10 vp | 文字区 right padding |
| 图片圆角 | 12 vp | 图片边框圆角 |

### 2.4 图片规格

| 属性 | 值 |
|------|-----|
| 宽度 | 132 vp（约占卡片宽度 42%） |
| 高度 | 120 vp（比宽度短约 9%，横向矩形） |
| 圆角 | 12 vp |
| 填充方式 | `ImageFit.Cover` |
| 占位兜底 | `.alt($r('app.media.icon'))` |
| 对齐 | 右侧，垂直居中 |

### 2.5 布局逻辑

```
┌──────────────────────────────────────────────┐
│ 14vp padding                                 │
│ ┌───────────────────────┐  ┌──────────┐      │
│ │ 标题 (14fp/#99000000)  │  │          │      │
│ │       10vp ↓           │  │  图片    │      │
│ │ 正文 (17fp/500/#E5)    │  │ 132×120  │ 14vp │
│ │ 行高22vp, 最多3行      │  │  R12     │      │
│ │       10vp ↓           │  │          │      │
│ │ 备注 (14fp/#99000000)  │  │          │      │
│ └───────────────────────┘  └──────────┘      │
│ ← 文字区 flex 自适应 →     ← 132vp 图片 →    │
│ 无图片时文字区 100% 宽                        │
└──────────────────────────────────────────────┘
```

**状态**：
- **有图**：文字 flex + 图片 132×120vp 右对齐，正文最多 3 行
- **无图**：文字 100% 宽度，正文最多 3 行
- **无标题**：标题行不渲染，正文从顶部开始
- **无备注**：备注行不渲染，正文直接到底部

### 2.6 交互设计

| 交互 | 实现 | 说明 |
|------|------|------|
| 卡片点击 | `postCardAction` router | 跳转到 EntryAbility，传参 `targetPage: debug` |
| 图片兜底 | `.alt($r('app.media.icon'))` | 图片加载失败时显示应用图标 |

### 2.7 色彩参考

| 用途 | Hex | 说明 |
|------|-----|------|
| 卡片背景 | `#FFFFFF` | 纯白底，系统桌面背景自动提供对比 |
| 正文（最深） | `#E5000000` | rgba(0,0,0,0.90) — 第一视觉层级 |
| 标题/备注（辅助） | `#99000000` | rgba(0,0,0,0.60) — 第二视觉层级 |
| 图片兜底色 | 无 | 系统默认占位 |

## 三、style=infoShowTitleImageAndImport（图片导入卡）

> **新增风格**。图片铺满整张卡片作为背景，右侧两个半透明操作按钮引导用户拍照或选图导入。

### 3.1 基础规格

| 属性 | 值 |
|------|-----|
| 背景 | `imageUrl` 指向的图片铺满整张卡片区域 |
| 图片填充方式 | `ImageFit.Cover` |
| 图片圆角 | 16 vp（跟随卡片圆角） |
| 占位兜底 | `.alt($r('app.media.icon'))` |
| 遮罩 | 无额外遮罩，图片原色呈现 |

### 3.2 必需/可选参数

| 参数 | 必需 | 说明 |
|------|------|------|
| `body` | **必填** | 卡片的正文字段 |
| `imageUrl` | 可选 | 背景图片 URL。有图时全幅铺满+右侧按钮；无图时只显示 body 文字，上部左对齐 |
| `title` | 此风格下忽略 | — |
| `note` | 此风格下忽略 | — |

> `infoShowTitleImageAndImport` 风格的卡片只使用 `body` 和 `imageUrl` 两个字段。`title` 和 `note` 在此风格下不参与渲染。

### 3.3 按钮规格

卡片右侧并排两个上下分布的操作按钮，尺寸完全一致：

| 属性 | 值 |
|------|-----|
| 宽度 | 48 vp |
| 高度 | 48 vp |
| 宽高比 | 1:1（正方形） |
| 圆角 | 12 vp |
| 位置 | 卡片右侧，垂直居中排列 |
| 间距 | 8 vp（上下两个按钮之间） |
| 右边距 | 14 vp（按钮组距离卡片右边缘） |

### 3.4 按钮颜色

| 属性 | Hex | 說明 |
|------|-----|------|
| 背景色 | `rgba(236,243,255,0.70)` ≈ `#B3ECF3FF` | 半透明浅蓝，与导入页拍照/相册按钮背景色 `#ECF3FF` 同源 |
| 边框色 | `rgba(213,226,250,0.70)` ≈ `#B3D5E2FA` | 半透明浅蓝边，与导入页按钮边框 `#D5E2FA` 同源 |
| 文字色 | `#1D5DD8` | 深蓝，与导入页按钮文字色一致 |
| 图标色 | `#1D5DD8` | 与文字同色 |

> 半透明度 ~70% 确保按钮在大部分背景图上可辨识，同时不完全遮挡背景图内容。

### 3.5 排版

- 按钮内图标+文字上下排列，或纯文字居中
- 上方按钮显示"拍一拍"（或相机图标 + "拍照"）
- 下方按钮显示"选一选"（或相册图标 + "选图"）
- 字号：11 fp，字重 Medium (500)

### 3.6 布局逻辑

```
┌──────────────────────────────────────────────┐
│                                              │
│                                              │
│           Image (fills entire card)           │
│           ImageFit.Cover                     │
│           borderRadius(16)                    │
│                                              │
│                              ┌──────────┐    │
│                              │  📷 拍一拍 │    │
│                              │  48×48    │ 14vp
│                              │  R12      │    │
│                              │  ──8vp──  │    │
│                              │  🖼 选一选 │    │
│                              │  48×48    │    │
│                              │  R12      │    │
│                              └──────────┘    │
│                                              │
└──────────────────────────────────────────────┘
```

**层级关系**：
1. **底层**：图片（Image），铺满全卡 `width('100%').height('100%')`
2. **上层**：按钮容器 Column（右侧垂直居中），内含两个相同尺寸的半透明按钮

### 3.7 交互设计

| 交互 | 实现 | 参数 |
|------|------|------|
| 点击"拍一拍" | `postCardAction` router → EntryAbility | `{ targetPage: 'import', importAction: 'camera' }` |
| 点击"选一选" | `postCardAction` router → EntryAbility | `{ targetPage: 'import', importAction: 'gallery' }` |
| 点击卡片其他区域 | `postCardAction` router → EntryAbility | `{ targetPage: 'import' }` |
| 图片兜底 | `.alt($r('app.media.icon'))` | 图片加载失败时显示默认图标 |

> **路由行为说明**：EntryAbility 收到 `targetPage: 'import'` 后切换到 ImportPage。若同时附带 `importAction`，ImportPage 在 `aboutToAppear` 中读取该参数并自动触发对应操作——`'camera'` 模拟点击拍照按钮，`'gallery'` 模拟点击相册按钮。

### 3.8 色彩参考

| 用途 | Hex | 说明 |
|------|-----|------|
| 按钮背景 | `rgba(236,243,255,0.70)` | 半透明浅蓝底，来源自 ImportPage 按钮 `#ECF3FF` |
| 按钮边框 | `rgba(213,226,250,0.70)` | 半透明浅蓝边，来源自 ImportPage 按钮 `#D5E2FA` |
| 按钮文字/图标 | `#1D5DD8` | 深蓝，来源自 ImportPage 按钮文字色 |
| 图片兜底 | 系统默认 | `.alt()` 灰色占位 |

## 四、两种卡片对比总览

| 维度 | infoShowTitleBodyNoteImage | infoShowTitleImageAndImport |
|------|---------------------------|----------------------------|
| 主体 | 左文字 + 右缩略图 | 全幅背景图 |
| 文字字段 | title, body, note | body（必填） |
| 图片角色 | 辅助缩略图（132×120vp） | 全幅背景（铺满卡片） |
| 交互元素 | 整卡点击 → debug 页 | 整卡点击 + 右侧两个快捷按钮 |
| 适用场景 | 日常信息/提醒展示 | 引导用户拍照/选图导入 |
| 默认风格 | **是**（`style` 不传时默认） | 否 |

---

## 五、与设计指南的对齐

| 华为设计指南要求 | 本卡片实现 |
|------------------|-----------|
| 16vp 系统圆角 | `borderRadius(16)` |
| 12~14vp 安全间距 | 四周 14vp（信息展示卡）/ 按钮区 14vp（图片导入卡） |
| 内容优先、减少留白 | 17/14fp 字体，正文加粗，舒朗间距 |
| 最多 3 种设计元素 | 信息展示卡：标题+正文+备注+图 / 图片导入卡：全幅图+2 按钮 |
| 左对齐布局 | `HorizontalAlign.Start`（信息展示卡） |
| 不支持滑动/拖拽 | 纯展示卡片，按钮使用 postCardAction 路由 |
