# 大桌面卡片 UI 设计文档

> 基于 HarmonyOS Design 官方规范的 2×4 服务卡片视觉设计。

---

## 一、卡片规格

| 属性 | 值 |
|------|-----|
| 卡片类型 | 中卡片 (2×4 Grid) |
| 设计尺寸 | 316 × 150 vp |
| 安全边距 | 四周 14 vp（略宽于官方 12vp，增加呼吸感） |
| 系统圆角 | 16 vp（由系统宿主自动裁剪） |
| 背景色 | `#FFFFFF` 纯白 |
| 阴影/描边 | 无（由系统桌面自动提供层级感） |

---

## 二、排版体系

遵循 HarmonyOS Design 的三级字体系统：

| 层级 | 元素 | 字号 | 字重 | 颜色 | 行高 |
|------|------|------|------|------|------|
| H1 | 标题 | 14 fp | 500 (Medium) | `rgba(0,0,0,0.90)` `#E5000000` | — |
| H2 | 正文 | 12 fp | 400 (Regular) | `rgba(0,0,0,0.60)` `#99000000` | 18 vp |
| H3 | 备注 | 10 fp | 400 (Regular) | `rgba(0,0,0,0.40)` `#66000000` | — |

**设计原则**：
- 文本色彩不超过 2 个级别跨度（标题用 90% 黑，正文用 60% 黑）
- 正文设置行高 18vp，保证多行文本可读性
- 图片右侧时正文最多 3 行，无图时最多 5 行

---

## 三、间距规范

遵循 4 vp 倍数体系：

| 间距 | 值 | 用途 |
|------|-----|------|
| 卡片内边距 | 14 vp | 左右上下的统一 padding |
| 标题→正文 | 6 vp | `margin({ bottom: 6 })` |
| 正文→备注 | 6 vp | `margin({ top: 6 })` |
| 文字→图片 | 8 vp | 右侧图片 margin |
| 图片圆角 | 12 vp (RadiusM) | 图片边框圆角 |

---

## 四、布局逻辑

```
┌──────────────────────────────────────────┐
│ 14vp padding                             │
│ ┌────────────────────┐  ┌──────┐         │
│ │ 标题 (14fp/500)    │  │      │         │
│ │       6vp ↓        │  │ 图片 │         │
│ │ 正文 (12fp/400)    │  │56×56 │ 14vp    │
│ │ 行高18vp, 3~5行    │  │ R12  │         │
│ │       6vp ↓        │  │      │         │
│ │ 备注 (10fp/400)    │  │      │         │
│ └────────────────────┘  └──────┘         │
│ ← 文字区 60% 宽 →     ← 图片区 →         │
│ 无图片时文字区 100% 宽                    │
└──────────────────────────────────────────┘
```

**状态**：
- **有图**：文字 60% + 图片 56×56vp 右对齐
- **无图**：文字 100% 宽度，正文更多行数 (5 行)
- **无标题**：标题行不渲染，正文从顶部开始
- **无备注**：备注行不渲染，正文直接到底部

## 五、交互设计

| 交互 | 实现 | 说明 |
|------|------|------|
| 卡片点击 | `postCardAction` router | 跳转到 EntryAbility，传参 `targetPage: debug` |
| 图片兜底 | `.alt($r('app.media.icon'))` | 图片加载失败时显示应用图标 |

## 六、色彩参考

| 用途 | Hex | 说明 |
|------|-----|------|
| 卡片背景 | `#FFFFFF` | 纯白底，系统桌面背景自动提供对比 |
| 主文字 | `#E5000000` | rgba(0,0,0,0.90) 标题级 |
| 次文字 | `#99000000` | rgba(0,0,0,0.60) 正文级 |
| 三级文字 | `#66000000` | rgba(0,0,0,0.40) 备注级 |
| 图片兜底色 | 无 | 系统默认占位 |

---

## 七、与设计指南的对齐

| 华为设计指南要求 | 本卡片实现 |
|------------------|-----------|
| 16vp 系统圆角 | `borderRadius(16)` |
| 12~14vp 安全间距 | 四周 14vp |
| 14/12/10 三级字体 | 标准 HarmonyOS Sans |
| 最多 3 种设计元素 | 标题+正文+备注+可选图 |
| 左对齐布局 | `HorizontalAlign.Start` |
| 不支持滑动/拖拽 | 纯展示卡片 |
| 适老化：≤1.3 倍放大 | 系统自动处理 |
